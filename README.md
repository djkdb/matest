# 🎯 시험 마스터 (Exam Master)

자격증 시험 준비의 시작과 끝. **시험과 시험일을 고르면**, 커뮤니티 곳곳(디시인사이드 · 네이버 카페 · 인스타그램 · 유튜브)의 **합격 꿀팁을 모아 보여주고**, 마음에 드는 전략을 골라 **남은 기간 공부량에 맞는 학습 캘린더를 자동 생성**해주는 앱입니다.

## 사용 흐름

1. **시험 선택** — 정보처리기사, 컴활 1급, 한국사능력검정, 토익, SQLD, 전기기사, 산업안전기사, 공인중개사 등 검색·카테고리 필터
2. **시험일 선택** — 다가오는 회차를 고르거나 직접 입력 → D-day 자동 계산
3. **꿀팁 모아보기** — 커뮤니티별 필터(디시/카페/인스타/유튜브), 추천수 정렬. 각 팁에는 **공부 전략**(개념/기출/모의고사/총정리 비중 + 권장 총 시간)이 달려 있고, 여러 개 고르면 전략이 **합성**됩니다
4. **공부량 설정** — 하루 공부 시간(30분~8시간), 쉬는 요일 설정. 선택한 전략의 권장 시간과 내 공부량을 비교해 부족/적정/여유 피드백
5. **캘린더 자동 생성** — 시험 전날까지 개념 → 기출 → 실전 모의고사 → 오답·총정리 순서로 학습 유닛을 일별 배분. 체크로 진행률 관리, **밀린 일정은 버튼 한 번으로 남은 날에 재분배**

모든 상태는 `localStorage`에 저장되어 새로고침해도 유지됩니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 계획 생성 엔진 단위 테스트
npm run build    # 프로덕션 빌드
```

## 프로젝트 구조

```
src/
├── App.jsx                  # 위저드 상태 머신 + 영속화
├── data/
│   ├── exams.js             # 자격증 DB (과목, 기출 회차 수, 데모 일정)
│   └── tips.js              # 커뮤니티 꿀팁 시드 데이터 (전략 파라미터 포함)
├── lib/
│   ├── planner.js           # ★ 계획 생성 엔진: 전략 합성 → 유닛 생성 → 일별 배분 → 재분배
│   ├── tipService.js        # 꿀팁 수집 API 추상화 (크롤러 백엔드 교체 지점)
│   ├── date.js              # 'YYYY-MM-DD' 기반 날짜 유틸
│   └── storage.js           # localStorage 영속화
└── components/
    ├── ExamPicker.jsx       # 1단계: 시험 선택
    ├── SchedulePicker.jsx   # 2단계: 시험일/D-day
    ├── TipsBoard.jsx        # 3단계: 꿀팁 피드 + 전략 선택
    ├── PlanSetup.jsx        # 4단계: 공부량 설정
    └── CalendarView.jsx     # 5단계: 월간 캘린더 + 진행 체크 + 재분배
```

## 계획 생성 엔진 (`src/lib/planner.js`)

- **전략 합성**: 선택한 팁들의 단계별 비중(`phaseWeights`)을 평균 내 최종 비중 결정
- **유닛 생성**: 총 가용 시간 × 단계 비중 예산에 맞춰 과목별 개념 회독, 기출 회차 회독(최대 3회독), 모의고사, 총정리 유닛 생성 (유닛당 30~180분)
- **일별 배분**: 휴식 요일을 제외한 학습 가능일에 단계 순서대로 채움 → 시험 직전엔 자연스럽게 총정리가 오도록 보장
- **재분배**: 유닛에 안정적인 id가 있어 완료 체크를 유지한 채, 미완료 유닛만 오늘부터 다시 배분

## 커뮤니티 데이터에 대해

현재 꿀팁과 시험 일정은 **번들에 포함된 데모 데이터**입니다. UI는 `tipService.fetchTips(examId)` 반환 형태에만 의존하므로, 실서비스 전환 시 이 함수만 수집 백엔드 API 호출로 교체하면 됩니다.

실서비스 로드맵:

1. **수집 백엔드**: 각 플랫폼의 공개 API·제휴·약관을 준수하는 수집기 (플랫폼별 크롤링 정책 및 저작권 검토 필수)
2. **정제 파이프라인**: 게시글 → 요약, 태그, 전략 파라미터(단계 비중·권장 시간) 추출 — LLM 기반 구조화에 적합
3. **공식 일정 연동**: 큐넷 등 공공데이터 API로 실제 시험 일정 자동 갱신
4. **알림/동기화**: 오늘의 할 일 푸시, 구글 캘린더 내보내기

⚠️ 앱에 내장된 시험 일정은 예시이며, 실제 접수는 반드시 시행 기관 공고를 확인해야 합니다.
