# 🎯 시험 마스터 (Exam Master)

자격증 시험 준비의 시작과 끝. **시험과 시험일을 고르면**, 커뮤니티 곳곳(디시인사이드 · 네이버 카페 · 인스타그램 · 유튜브)의 **합격 꿀팁을 모아 보여주고**, 마음에 드는 전략을 골라 **남은 기간 공부량에 맞는 학습 캘린더를 자동 생성**해주는 앱입니다.

📱 **휴대폰 앱(PWA)** 으로 설치하면 홈 화면 아이콘으로 바로 열리고, 전체화면으로 실행되며, 오프라인에서도 동작합니다. (설치 방법은 아래 [휴대폰 앱으로 설치](#-휴대폰-앱으로-설치-pwa) 참고)

## 사용 흐름

1. **시험 선택** — 정보처리기사, 컴활 1급, 한국사능력검정, 토익, SQLD, 전기기사, 산업안전기사, 공인중개사 등 검색·카테고리 필터
2. **시험일(회차) 선택** — **큐넷 공공데이터 API로 실제 회차를 조회**해 필기/실기별 **원서접수(시험 신청)일·시험일·합격발표일**을 보여줍니다. "접수 시작 D-n / 접수 중 / 접수 마감" 상태로 신청 타이밍을 놓치지 않게 안내 → D-day 자동 계산
3. **꿀팁 모아보기** — 커뮤니티별 필터(디시/카페/인스타/유튜브), 추천수 정렬. 각 팁에는 **공부 전략**(개념/기출/모의고사/총정리 비중 + 권장 총 시간)이 달려 있고, 여러 개 고르면 전략이 **합성**됩니다
4. **공부량 설정** — 하루 공부 시간(30분~8시간), 쉬는 요일 설정. 선택한 전략의 권장 시간과 내 공부량을 비교해 부족/적정/여유 피드백
5. **캘린더 자동 생성** — 시험 전날까지 개념 → 기출 → 실전 모의고사 → 오답·총정리 순서로 학습 유닛을 일별 배분. 체크로 진행률 관리, **밀린 일정은 버튼 한 번으로 남은 날에 재분배**. 캘린더에 **원서접수 시작·마감일, 합격발표일**이 함께 표시되고, 상단에 "원서접수 시작까지 D-n" 알림 배너가 뜹니다.
6. **캘린더 내보내기(.ics)** — 원서접수 시작·마감, 시험일, 합격발표, (옵션) 하루치 공부 일정을 **구글·애플·아웃룩 캘린더로 내보내기**. 각 이벤트에 알림(VALARM)이 들어 있어 앱을 켜두지 않아도 내 캘린더 앱이 **"원서접수 3일 전 / 내일 마감 / 시험 1주일 전"** 등을 알려줍니다.
7. **공부 타이머 + 연속 학습일(스트릭)** — 캘린더 화면 상단에서 **공부 시간을 측정**하고, 매일 공부하면 **🔥 N일 연속** 스트릭이 쌓입니다. 최근 7일 공부량 막대 그래프로 꾸준함을 시각화(열품타식 동기부여). 백엔드 없이 로컬 저장, 진행 중 세션은 새로고침에도 복원됩니다. 근거: 소셜/스트릭 게이미피케이션이 학습앱 리텐션의 핵심 동인(딥리서치 반영).

모든 상태는 `localStorage`에 저장되어 새로고침해도 유지됩니다.

## 🎨 디자인 시스템

실서비스급 한국 앱(토스 계열)의 UI 원칙을 따릅니다 — 뉴트럴 그레이스케일 + 단일 블루 액센트, 큰 볼드 타이포, 플랫한 표면, 얇은 구분선, 절제된 그림자.

- **Pretendard 폰트** — 한국 앱 표준 서체를 자체 호스팅(`public/fonts/PretendardVariable.woff2`). 첫 로드 후 서비스워커가 캐시해 오프라인에서도 렌더링
- **팔레트** — 텍스트 `#191F28`, 액센트 `#3182F6` 등 뉴트럴+블루 단일 계통. 이모지를 UI 아이콘으로 쓰지 않고 SVG 라인 아이콘(`Icon.jsx`) 사용
- **라이트/다크 자동** — `prefers-color-scheme` 기반, CSS 변수 토큰으로 두 테마 관리
- **스크롤 등장·스태거** — `Reveal`(IntersectionObserver)로 카드가 순차 등장
- **애니메이션 D-day·진행률 링** — `AnimatedNumber` 카운트업 + `ProgressRing`
- **축하 효과** — `confetti.js`(의존성 0)로 계획 생성·100% 달성 시 컨페티, 유닛 완료 시 작은 버스트
- **접근성** — `prefers-reduced-motion`이면 모션·컨페티를 자동 비활성화

관련 파일: `src/styles.css`(토큰+다크), `src/components/{Icon,Reveal,AnimatedNumber,ProgressRing}.jsx`, `src/lib/confetti.js`.

## 📱 휴대폰 앱으로 설치 (PWA)

이 앱은 **PWA(Progressive Web App)** 라서 스토어 없이 홈 화면에 설치할 수 있습니다.
설치하면 주소창 없는 전체화면으로 실행되고, 서비스워커가 앱 셸을 캐시해 **오프라인에서도** 열립니다.

- **안드로이드 / 크롬**: 접속하면 상단에 "홈 화면에 추가" 배너가 뜹니다. 누르거나, 브라우저 메뉴 → "앱 설치 / 홈 화면에 추가"를 선택하세요.
- **아이폰 / 사파리**: 하단 **공유 버튼** → **"홈 화면에 추가"** 를 선택하세요. (iOS는 자동 설치 배너를 지원하지 않아 앱이 안내 문구를 표시합니다.)

구성 요소:

- `vite.config.js` 의 `VitePWA` — 매니페스트(`manifest.webmanifest`)와 서비스워커(`sw.js`) 자동 생성, 앱 셸 프리캐시, 새 버전 자동 업데이트(`registerType: 'autoUpdate'`). 큐넷 API(`/api/qnet`)는 캐시하지 않습니다(`NetworkOnly`).
- `public/icons/` — 앱 아이콘(192·512·maskable), `public/apple-touch-icon.png`
- `src/components/InstallPrompt.jsx` — 설치 배너/ iOS 안내
- `index.html` — `theme-color`, `apple-mobile-web-app-*`, `viewport-fit=cover`(노치 세이프 에어리어) 메타
- 모바일 레이아웃: 세이프 에어리어 패딩, 가로 스크롤 방지, 터치 타깃 확대, 캘린더 세로 스택

> 참고: 서비스워커는 HTTPS(또는 localhost)에서만 동작합니다. `npm run build && npm run preview` 로 로컬 확인하거나, HTTPS로 배포하세요.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173 (개발용 — PWA 서비스워커는 비활성)
npm test         # 단위 테스트 (계획 엔진 · 큐넷 파싱 · ICS 생성)
npm run build    # 프로덕션 빌드 (매니페스트 + 서비스워커 생성)
npm run preview  # 빌드 결과 로컬 확인 — PWA 설치/오프라인 테스트는 여기서
```

## 계획 생성 엔진 (`src/lib/planner.js`)

- **전략 합성**: 선택한 팁들의 단계별 비중(`phaseWeights`)을 평균 내 최종 비중 결정
- **유닛 생성**: 총 가용 시간 × 단계 비중 예산에 맞춰 과목별 개념 회독, 기출 회차 회독(최대 3회독), 모의고사, 총정리 유닛 생성 (유닛당 30~180분)
- **일별 배분**: 휴식 요일을 제외한 학습 가능일에 단계 순서대로 채움 → 시험 직전엔 자연스럽게 총정리가 오도록 보장
- **재분배**: 유닛에 안정적인 id가 있어 완료 체크를 유지한 채, 미완료 유닛만 오늘부터 다시 배분

## 큐넷 시험일정 API 연동 (`src/lib/qnetService.js`)

정보처리기사·전기기사·산업안전기사·지게차운전기능사 등 **국가기술자격**은
공공데이터포털의 **한국산업인력공단 국가기술자격 시험일정 API**로 실제 회차를
조회합니다. 응답의 필기/실기 원서접수·시험·합격발표 일자(`docRegStartDt`,
`pracExamStartDt` 등)를 앱의 회차(session) 구조로 정규화합니다.

**인증키 설정 (실시간 일정 켜기)**

1. [공공데이터포털](https://www.data.go.kr)에서 "한국산업인력공단_국가기술자격 시험일정"
   오픈API 활용신청 → 일반 인증키(Decoding) 발급
2. `.env.example` → `.env.local` 복사 후 `VITE_QNET_API_KEY` 에 키 입력
3. `npm run dev` — 시험일 화면에 🟢 **큐넷 실시간 일정** 배지가 뜨면 연동 성공

**동작 방식**

- 브라우저에서 `apis.data.go.kr` 직접 호출은 CORS로 막히므로, 개발 중에는
  `vite.config.js` 의 `/api/qnet` 프록시가 공공데이터포털로 요청을 전달합니다.
  배포 시에는 같은 경로를 서버리스 함수/리버스 프록시로 연결하세요(인증키를
  서버에서 주입하면 키 노출도 막을 수 있습니다).
- **인증키가 없거나 요청이 실패하면** 각 시험의 예시 일정(`scheduleFallback`)으로
  자동 폴백하며, 화면에는 📄 **예시 일정** 배지가 표시됩니다.
- 어학(토익)·상공회의소(컴활)·전문자격(공인중개사·사회복지사) 등 큐넷 대상이
  아닌 시험은 `qnet: null` 로 두어 항상 예시 일정을 사용합니다. (해당 기관 API
  연동은 로드맵)

> ⚠️ 이 샌드박스/CI 환경은 네트워크 정책상 `apis.data.go.kr` 접근이 차단되어
> 있어 라이브 응답 테스트는 사용자 인증키 + 브라우저 런타임에서 확인해야 합니다.
> 응답 파싱·정규화 로직은 `tests/qnet.test.mjs` 단위 테스트로 검증합니다.

## 캘린더 내보내기 (`src/lib/ics.js`)

캘린더 화면의 **📅 캘린더 내보내기 (.ics)** 버튼으로 표준 iCalendar 파일을
생성합니다. 구글 캘린더(설정 → 가져오기), 애플 캘린더, 아웃룩 등에서 열면:

- **원서접수 시작** — 3일 전·전날 알림
- **원서접수 마감** — 전날·당일 오전 9시 알림("오늘 마감!")
- **시험일** — 1주 전·전날·당일 오전 알림
- **합격 발표일**
- (체크박스로 선택) **하루치 공부 일정** — 그 날의 학습 유닛 목록

각 이벤트에 `VALARM`(알림)이 포함되어, 앱을 켜두지 않아도 사용자의 캘린더 앱이
직접 리마인더를 띄웁니다. 별도 백엔드나 푸시 서버 없이 완전히 클라이언트에서
동작합니다. 생성 로직은 순수 함수라 `tests/ics.test.mjs` 로 검증합니다
(라인 폴딩·이스케이프·VALARM·CRLF 등 RFC 5545 준수).

## 커뮤니티 데이터에 대해

현재 꿀팁과 시험 일정은 **번들에 포함된 데모 데이터**입니다. UI는 `tipService.fetchTips(examId)` 반환 형태에만 의존하므로, 실서비스 전환 시 이 함수만 수집 백엔드 API 호출로 교체하면 됩니다.

실서비스 로드맵:

1. **수집 백엔드**: 각 플랫폼의 공개 API·제휴·약관을 준수하는 수집기 (플랫폼별 크롤링 정책 및 저작권 검토 필수)
2. **정제 파이프라인**: 게시글 → 요약, 태그, 전략 파라미터(단계 비중·권장 시간) 추출 — LLM 기반 구조화에 적합
3. **공식 일정 연동**: 큐넷 국가기술자격 API 연동 완료 ✅ / 국가전문자격(공인중개사·사회복지사)은 `qnet.operation` 설정만으로 확장 가능하도록 일반화(엔드포인트 확인 후 연결) / 상공회의소·어학은 공개 API 부재로 제휴 필요
4. **동기화/알림**: 구글·애플 캘린더 내보내기(.ics) 완료 ✅ / 웹푸시(서비스워커+푸시서버)로 앱 미실행 시에도 원서접수 알림

⚠️ 앱에 내장된 시험 일정은 예시이며, 실제 접수는 반드시 시행 기관 공고를 확인해야 합니다.
